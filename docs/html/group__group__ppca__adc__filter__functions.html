void Cy_PPCA_ADC_Filter_Init ( ATOPSS_ADCFLT_TYPE *  base,
cy_stc_ppca_adc_filter_config_t const *  config 
)

Initializes and enables the ADC Filter module.

Configures the digital filter chain (Median, Linear Interpolation, Low-Pass, CIC3, Averaging), MIN/MAX detection, bypass settings, and CIC digital comparator thresholds.

Parameters
baseThe pointer to the ADC filter instance address.
configThe pointer to the filter config structure cy_stc_ppca_adc_filter_config_t.
