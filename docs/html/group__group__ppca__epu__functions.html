◆ Cy_PPCA_EPU_PU_T1_Configure()

void Cy_PPCA_EPU_PU_T1_Configure ( PPCA_EPU_EPU_Type *  base,
uint32_t  index,
cy_stc_ppca_epu_PU_T1_config_t const *  config 
)

Configures a Processing Unit Type 1 module including PRESTAGE (input source, polarity inversion, edge extraction, qualifier) and MXSTAGE (processing function, clock cycle duration).

This writes the full PU_T1 configuration in a single operation. The PU is kept disabled after configuration. Use Cy_PPCA_EPU_PU_T1_Enable to enable the PU after configuration.

Parameters
*baseThe PPCA EPU registers structure pointer.
indexThe Processing Unit Type 1 index (PUT1). Range: 0-31.
configThe pointer to the PU_T1 configuration structure cy_stc_ppca_epu_PU_T1_config_t.

◆ Cy_PPCA_EPU_PU_T2_Configure()

void Cy_PPCA_EPU_PU_T2_Configure ( PPCA_EPU_EPU_Type *  base,
uint32_t  index,
cy_stc_ppca_epu_PU_T2_config_t const *  config 
)

Configures a Processing Unit Type 2 module.

PU_T2 modules provide PRESTAGE-only processing (input source, polarity inversion, edge extraction) without MXSTAGE signal conditioning. The PU is kept disabled after configuration. Use Cy_PPCA_EPU_PU_T2_Enable to enable the PU after configuration.

Parameters
*baseThe PPCA EPU registers structure pointer.
indexThe Processing Unit Type 2 index (PUT2). Range: 0-15.
configThe pointer to the PU_T2 configuration structure cy_stc_ppca_epu_PU_T2_config_t.

uint32_t  index,
uint32_t  comboFBSrcIn 
)

Configures a COMBO Feedback path.

Up to 8 COMBO outputs can be fed back into the EPU input space, enabling cascaded trigger logic where the output of one COMBO block serves as an input event for subsequent processing.

Parameters
*baseThe PPCA EPU registers structure pointer.
indexThe COMBO Feedback block index. Range: 0-7.
comboFBSrcInThe COMBO output index to feed back. Range: 0-122.

__STATIC_INLINE uint32_t Cy_PPCA_EPU_GetInterruptStatusMasked ( PPCA_EPU_EPU_IRQ_Type *  base)

Returns the interrupt masked register.

This register contains a logical AND of corresponding bits from the interrupt cause and mask registers. This function is intended to be used in the interrupt service routine to identify which of enabled interrupt sources caused the interrupt event.

Parameters
baseThe pointer to the PPCA_EPU_EPU_IRQ instance.
Returns
The current status of enabled interrupt sources.
