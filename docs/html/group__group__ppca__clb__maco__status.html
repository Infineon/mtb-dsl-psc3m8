PDL API Reference » PPCA (Programmable Power Control Accelerator ) » CLB (Custom Logic Block) » MACO » Macros

General Description

Macros to check current MACO status returned by Cy_PPCA_CLB_MACO_ReadStatus function.

Each status is encoded in a separate bit, therefore multiple bits may be set to indicate the current status.
