General Description

The MXS40ATOPSS (Analog Top SubSystem) provides the analog front-end for the Programmable Power Control Accelerator (PPCA).

It operates autonomously, independent of the chip main CPU, and is fully controlled by the PPSS embedded processors or by an external bus master.

Overview

The ATOPSS contains the following analog blocks:

  • 4 ADC instances (SAR, 12-bit, up to 25 MSPS) organized in groups (ADC_GRP_0, ADC_GRP_1, ADC_GRP_2, ADC_GRP_3) each with its own AFE
  • 2 ADC Filter blocks per ADC with Median, Linear Interpolation, Low-Pass, CIC3, and Averaging stages plus MIN/MAX detection
  • 9 DCSG slices (Digital Comparator and Slope Generator) organized in two groups: GRP_0 (6 slices) and GRP_1 (3 slices)
  • 2 R2R DACs (12-bit, up to 2 MHz refresh rate)
  • 1 IDAC (current output DAC for sensor biasing)
  • 2 Input MUXes for flexible analog channel routing
  • 1 Temperature Sensor (TSNS) for on-chip temperature measurement
  • 1 AREF (Analog Reference) providing bandgap voltage and current references for all analog blocks

The ATOPSS is accessed through 6 AHB5 slave interfaces and supports hardware triggered operation via the EPU trigger bus.

API Reference

 ADC
 The ADC driver provides an interface to the SAR (Successive Approximation Register) ADC and its associated Analog Front End (AFE) within the ATOPSS.
 
 ADC Filter
 The ADC Filter driver provides an interface to the digital filter chain attached to each ADC group within the ATOPSS.
 
 AREF
 The AREF driver provides an interface to the Analog Reference block, the IDAC (current-output DAC), and the GPI (General Purpose Input) modules within the ATOPSS.
 
 DAC (DAC R2R)
 The DAC R2R driver provides an interface to the 12-bit R2R-ladder Digital-to-Analog Converter within the ATOPSS.
 
 DCMP (Digital Comparator)
 The DCMP (Digital Comparator) driver provides an interface to the 12 digital comparator modules within the ATOPSS ADC_GRP_IF blocks.
 
 DCSG (Differential Comparator And Slope Generator)
 The DCSG (Digital Comparator and Slope Generator) driver provides an interface to the analog comparator slices within the ATOPSS.
 
 DCSG SLGEN (Slope Generator)
 The DCSG Slope Generator (SLGEN) driver provides an interface to the hardware ramp generator embedded in each DCSG group.
