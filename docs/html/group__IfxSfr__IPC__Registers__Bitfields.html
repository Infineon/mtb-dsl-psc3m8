◆ Ifx_IPC_STRUCT_RELEASE_Bits

struct Ifx_IPC_STRUCT_RELEASE_Bits
Data Fields
__O Ifx_UReg_32Bit INTR_RELEASE:16 [15:0] Writing this field releases a lock and allows for the generation of release events to the IPC interrupt structures, but only when the lock is acquired (LOCK_STATUS.ACQUIRED is '1').

The IPC release cause fields associated with this IPC structure are set to '1', but only for those IPC interrupt structures for which the corresponding bit field in INTR_RELEASE[] is set to '1'. SW writes a '1' to the bit fields to generate a release event. Due to the transient nature of this event, SW always reads a '0' from this field. (w)

struct Ifx_IPC_STRUCT_NOTIFY_Bits
Data Fields
__O Ifx_UReg_32Bit INTR_NOTIFY:16 [15:0] This field allows for the generation of notification events to the IPC interrupt structures.

The IPC notification cause fields associated with this IPC structure are set to '1', but only for those IPC interrupt structures for which the corresponding bit field in INTR_NOTIFY[] is set to '1'. SW writes a '1' to the bit fields to generate a notify event. Due to the transient nature of this event, SW always reads a '0' from this field. (w)

struct Ifx_IPC_INTR_STRUCT_INTR_Bits
Data Fields
__IO Ifx_UReg_32Bit RELEASE:16 [15:0] These interrupt cause fields are activated (HW sets the field to '1') when a IPC release event is detected.

One bit field for each master. SW writes a '1' to these field to clear the interrupt cause. (rw)

__IO Ifx_UReg_32Bit NOTIFY:16 [31:16] These interrupt cause fields are activated (HW sets the field to '1') when a IPC notification event is detected.

One bit field for each master. SW writes a '1' to these field to clear the interrupt cause. (rw)
