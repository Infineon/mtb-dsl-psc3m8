◆ cy_en_ppca_filter_src_sel_t

enum cy_en_ppca_filter_src_sel_t

Source select for the DATA_IN1 data register.

Determines whether DATA_IN1 receives data from the CPU via AHB bus writes or automatically from the ADC filter output (datapath mode).

Enumerator
CY_AHB_IF 

DATA_IN1 is sourced from AHB interface (CPU writes).

Use this for CPU accelerator mode.

CY_DATA_PATH 

DATA_IN1 is sourced from the ADC Filter output (hardware datapath).

Use this for autonomous closed-loop control.

◆ cy_en_ppca_filter_data_sel_t

enum cy_en_ppca_filter_data_sel_t

Selects which data input register triggers filter processing.

Writing to the selected data register starts the filter computation. Only one trigger source should be enabled at a time.

Enumerator
CY_DISABLE_DATA_IN 

Both DATA_IN0 and DATA_IN1 trigger disabled.

Filter must be triggered by other means.

CY_ENABLE_DATA_IN0 

Filter processing is triggered by writing to DATA_IN0.

CY_ENABLE_DATA_IN1 

Filter processing is triggered by writing to DATA_IN1.

◆ cy_en_ppca_filter_scale_factor_t

enum cy_en_ppca_filter_scale_factor_t

Scale factors for coefficient normalization.

Each increment of the scale factor applies a left shift of 1 bit (multiplication by 2) to compensate for coefficients that were divided by 2 to fit within the [-1, +1) range. For example, if all B coefficients were divided by 4 (2 times by 2), set scaleCX = 2.

Enumerator
CY_SCALE_FACTOR_0 

No scaling applied (coefficients already in [-1, +1) range)

CY_SCALE_FACTOR_1 

Multiply output by 2^1 to compensate 1 coefficient halving.

CY_SCALE_FACTOR_2 

Multiply output by 2^2 to compensate 2 coefficient halvings.

CY_SCALE_FACTOR_3 

Multiply output by 2^3 to compensate 3 coefficient halvings.

CY_SCALE_FACTOR_4 

Multiply output by 2^4 to compensate 4 coefficient halvings.

CY_SCALE_FACTOR_5 

Multiply output by 2^5 to compensate 5 coefficient halvings.

CY_SCALE_FACTOR_6 

Multiply output by 2^6 to compensate 6 coefficient halvings.

CY_SCALE_FACTOR_7 

Multiply output by 2^7 to compensate 7 coefficient halvings.

◆ cy_en_ppca_filter_status_t

enum cy_en_ppca_filter_status_t

Filter busy status.

The filter becomes busy when a computation is triggered (by writing to a data input register) and returns to free after the computation completes (maximum 8 CPU clock cycles).

Enumerator
CY_FILTER_IS_FREE 

The filter is idle and ready to accept new input data.

CY_FILTER_IS_BUSY 

The filter is currently computing; output is not yet valid.
