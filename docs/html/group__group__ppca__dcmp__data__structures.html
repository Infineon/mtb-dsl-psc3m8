Data Fields
cy_en_dcmp_comparison_mode_t comparison_mode Comparison mode.
cy_en_dcmp_avg_sampling_window_t avg_sampling_window DCMP Average Sampling Window.
uint8_t src_ch Source Channel to DCMP.
bool inv_dcmp_ev If set The immediate comparison result of mode 0 will be inverted.
uint16_t dcmp_threshold 12 bit Digital Comparator Threshold value.

Can be signed or unsigned depending on the ADC Channel Signed and Unsigned

uint8_t dcmp_acc_threshold 8 bit Digital Comparator accumulate Threshold value.

DCMP result will be 1 if the Comparator result is greater than dcmp_acc_threshold.

◆ cy_en_dcmp_comparison_mode_t

enum cy_en_dcmp_comparison_mode_t

comparison method

Enumerator
CY_DCMP_MODE_IMMEDIATE_COMPARISON 

DCMP comparison method set to Immediate: A(n) > TH

CY_DCMP_MODE_INTEGRATION_OF_IMMEDIATE_COMPARISON 

DCMP comparison method set to Integration of Immediate: Sigma ((A(n) > TH) - (A(n) <= TH)) > TH_ACC

CY_DCMP_MODE_ACCUMULATE_OF_IMMEDIATE_COMPARISON 

DCMP comparison method set to accumulation of Immediate: Sigma (A(n) > TH) > TH_ACC

CY_DCMP_MODE_AVERAGED_COMPARISON 

DCMP comparison method set to Average: 1/N Sigma A(n) > TH
