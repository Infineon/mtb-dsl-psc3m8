Data Fields
__IO Ifx_UReg_32Bit ENABLE:4 [3:0] '0101' = Disable SVGS.

All other values will enable SVGS. Note that HW will disable during DEEPSLEEP for power savings. (rw)

__I Ifx_UReg_32Bit:4 [7:4]

[31:9]

__IO Ifx_UReg_32Bit FAULT_EN:1 [8:8] 0 = Disable Fault generation 1 = A fault will be generated to the CPUSS fault handler for any enabled comparator.

Note that this fault will not be registered if the reset is not masked for the triggered comparator (reset takes precedence). (rw)
