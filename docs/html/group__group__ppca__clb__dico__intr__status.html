Macro Definition Documentation

◆ CY_DICO_INTR_PS_0

#define CY_DICO_INTR_PS_0   0x01U

Phase-Shift interrupt 0: fires when a completed switching cycle is measured by the MAX_ON_TIME timer (Fsys/4 clock).

This interrupt is generated autonomously by the DICO state machine independent of current accumulation. Fires even when FILT_OUT = 0 and no live converter is connected. See also Cy_PPCA_CLB_DICO_ConfigPhase1.

◆ CY_DICO_INTR_PS_1

#define CY_DICO_INTR_PS_1   0x02U

Phase-Shift interrupt 1: fires when a completed switching cycle is measured by the MAX_ON_TIME timer (Fsys/4 clock).

This interrupt is generated autonomously by the DICO state machine independent of current accumulation. Fires even when FILT_OUT = 0 and no live converter is connected. See also Cy_PPCA_CLB_DICO_ConfigPhase1.
