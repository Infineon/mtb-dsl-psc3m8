Data Fields
bool trigger_unmask if enabled, triggers are unmasked.

Upon detect of Trigger will start the SL operation.

bool single_clk_glitch if enabled, single clock blank glitch filter is enabled.
bool slgen_src if enabled, Select SLGEN RAMP as source, SLGEN_RAMP is control of the DAC threshold.

If disabled CPU is in control of DCSG_TH: DAC threshold

bool shadow_transfer Enable/Disable Shadow Transfer Feature.
bool auto_reset Enable/Disable Auto Reset Feature.

Auto-Reset of Slope Generation threshold between initial and target value.

cy_en_dcsg_slgen_map_t slgen_map map SL_GEN operation DCSG.
