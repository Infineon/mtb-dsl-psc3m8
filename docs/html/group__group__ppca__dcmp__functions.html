12 bit Digital Comparator Threshold value can be signed or unsigned depending on the ADC Channel Signed and Unsigned.

When DCMP threshold data is negative for sign, the 20 bits data returned will be all 1's.

Parameters
baseThe pointer to the DCMP instance address.
Returns
returns When DCMP threshold data is negative for sign, the 20 bits data returned will be all 1's, else 0's

__STATIC_INLINE uint8_t Cy_PPCA_DCMP_Get_Source_Channel ( ATOPSS_DCMP_TYPE *  base)

Returns the ADC channel number currently feeding this DCMP instance, as configured via cy_stc_ppca_dcmp_config_t.src_ch at Cy_PPCA_DCMP_Init().

Useful when the source channel assignment is not otherwise known to the calling code (e.g. generic test/verification routines).

Parameters
baseThe pointer to the DCMP instance address.
Returns
the ADC source channel number connected to this DCMP.
