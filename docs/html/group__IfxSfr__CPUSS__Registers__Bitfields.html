__IO Ifx_UReg_32Bit WRITE_BUFF:1 [0:0] Specifies if write transfer can be buffered in the bus infrastructure bridges: '0': Write transfers are not buffered, independent of the transfer's bufferable attribute.

'1': Write transfers can be buffered, if the transfer's bufferable attribute indicates that the transfer is a bufferable/posted write. This bit controls buffering only for subsystems that interfaced using the AHB2AHB bridge, not for components utilised from the ARM SIE200, such as the 32-bit SYS interconnect in SYSCPUSS, Peripheral Group0, MSC etc. (rw)
