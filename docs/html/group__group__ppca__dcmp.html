DCMP (Digital Comparator)
PDL API Reference » PPCA (Programmable Power Control Accelerator ) » ATOP

General Description

The DCMP (Digital Comparator) driver provides an interface to the 12 digital comparator modules within the ATOPSS ADC_GRP_IF blocks.

Each DCMP is connected to one of the converted ADC data channels and generates an event (DCMP_OUT) when the input (or elaborated input) crosses a programmed threshold.

Overview

The ATOPSS contains 12 DCMP instances distributed across four ADC groups:

  • ADC_GRP_0: 4 DCMP modules (DCMP_00 .. DCMP_03)
  • ADC_GRP_1: 2 DCMP modules (DCMP_10 .. DCMP_11)
  • ADC_GRP_2: 2 DCMP modules (DCMP_20 .. DCMP_21)
  • ADC_GRP_3: 4 DCMP modules (DCMP_30 .. DCMP_33)

The source ADC channel for each DCMP is selected through the configuration register (DCMP_CNFG.SEL_SRC_CH). The 12-bit threshold (DCMP_TH) can be signed or unsigned, matching the ADC channel data format.

Comparison Modes (DCMP_CNFG.MODE):

  • Mode 0 — Immediate: A(n) > TH. Comparison occurs as soon as data is ready. Invertible via INV_DCMP_EV_CNFG.
  • Mode 1 — Integration (Accumulate): Accumulates +1 for each A(n) > TH and -1 otherwise, capped at [0, 255]. Result compared against TH_ACC. Requires a trigger to start/reset.
  • Mode 2 — Increment: Accumulates +1 for each A(n) > TH, +0 otherwise, capped at 255. Result compared against TH_ACC. Requires a trigger to start/reset.
  • Mode 3 — Averaged: ROUND(1/N * Sigma A(n)) > TH. Averages over a window of 4, 16, 64, or 256 samples, then compares against TH. Requires a trigger to start.

Trigger Behavior: In Modes 1-3, DCMP_TRIGGER.DCMP_TRIG or the external DCMP_TRIG[] signal resets the accumulated computation and starts the comparison window. DCMP_OUT events are routed to the EPU trigger bus.

Note
DCMP_CNFG registers must not be changed while the DCMP is enabled. Disable the DCMP first, modify the configuration, then re-enable to prevent unexpected behavior.
