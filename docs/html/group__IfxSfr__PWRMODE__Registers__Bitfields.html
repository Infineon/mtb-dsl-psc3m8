__IO Ifx_UReg_32Bit PWR_POLICY:4 [3:0] Power mode policy.

When static power mode transitions are enabled, PWR_DYN_EN is set to 0, this is the target power mode for the PPU. When dynamic power mode transitions are enabled, PWR_DYN_EN is set to 1, this is the minimum power mode for the PPU. This PPU supports the following modes: OFF(0), MEM_RET(2), FULL_RET(5), ON(8). Do not use WARM_RST(9) or other unsupported modes. (rw)

__IO Ifx_UReg_32Bit WARM_RST_DEVREQEN:1 [0:0] Transition behavior between ON and WARM_RST.

This bit should not be modified when the PPU is in WARM_RST, or if the PPU is performing a transition, otherwise PPU behavior is UNPREDICTABLE. 0: The PPU does not perform a device interface handshake when transitioning between ON and WARM_RST. 1: The PPU performs a device interface handshake when transitioning between ON and WARM_RST.
