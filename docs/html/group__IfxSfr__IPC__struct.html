◆ INTR_RELEASE

__O Ifx_UReg_32Bit Ifx_IPC_STRUCT_RELEASE_Bits::INTR_RELEASE

[15:0] Writing this field releases a lock and allows for the generation of release events to the IPC interrupt structures, but only when the lock is acquired (LOCK_STATUS.ACQUIRED is '1').

The IPC release cause fields associated with this IPC structure are set to '1', but only for those IPC interrupt structures for which the corresponding bit field in INTR_RELEASE[] is set to '1'. SW writes a '1' to the bit fields to generate a release event. Due to the transient nature of this event, SW always reads a '0' from this field. (w)

◆ INTR_NOTIFY

__O Ifx_UReg_32Bit Ifx_IPC_STRUCT_NOTIFY_Bits::INTR_NOTIFY

[15:0] This field allows for the generation of notification events to the IPC interrupt structures.

The IPC notification cause fields associated with this IPC structure are set to '1', but only for those IPC interrupt structures for which the corresponding bit field in INTR_NOTIFY[] is set to '1'. SW writes a '1' to the bit fields to generate a notify event. Due to the transient nature of this event, SW always reads a '0' from this field. (w)
