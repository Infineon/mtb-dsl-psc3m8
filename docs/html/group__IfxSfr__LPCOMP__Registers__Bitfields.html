struct Ifx_LPCOMP_CONFIG_Bits
Data Fields
__I Ifx_UReg_32Bit:30 [29:0]
__IO Ifx_UReg_32Bit LPREF_EN:1 [30:30] Enable the local reference generator circuit to generate the local Vref and Ibias.

Ibias current is an alternative to the reference current IREF generated by SRSS. This bit must be set for System Deep Sleep and System Hibernate operation. (rw)

__IO Ifx_UReg_32Bit ENABLED:1 [31:31] - 0: LPCOMP disabled (puts analog in power down, opens all switches, all clocks turned off)
  • 1: LPCOMP enabled (rw)
