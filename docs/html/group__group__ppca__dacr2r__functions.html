void Cy_PPCA_DAC_Init ( ATOPSS_DAC_TYPE *  base,
cy_stc_ppca_dacr2r_config_t const *  config 
)

Initializes the 12-bit R2R DAC.

Configures the operating mode (loopback, buffered), correction features (offset, gain, buffer offset), and reference connections. Also loads trim values from the SFLASH region.

Parameters
baseThe pointer to the DACR2R instance address.
configThe pointer to the DAC config structure cy_stc_ppca_dacr2r_config_t.
Note
Must be called from the Main core so that trim registers are configured correctly. Trim values are not loaded if called from PPCA cores.
