◆ cy_en_ppca_cnfg_interrupts_t

enum cy_en_ppca_cnfg_interrupts_t

PPCA CNFG Interrupts Index.

Each enum value corresponds to one S2IRQ register block in the PPCA CNFG. The interrupt is forwarded from the PPCA subsystem to the host CM33 NVIC through the corresponding S2IRQ channel.

Note
CY_IRQ_RDY_FOR_DEEPSLEEP was available since ES10. The CTI and FP interrupt sources were added post-ES10.
Enumerator
CY_IRQ_RDY_FOR_DEEPSLEEP 

PPCA ready for DeepSleep.

Signals that the PPCA subsystem has completed all pending operations and is ready to enter DeepSleep mode. Maps to host IRQn ppca_cnfg_rdy_for_dslp_IRQn.

CY_IRQ_PPCA_CPU0_CTI_0 

PPCA CPU0 Cross-Trigger Interface (CTI) channel 0.

Triggered by the CoreSight CTI output 0 of PPCA CPU0. Maps to host IRQn ppca_cpu0_cti_0_IRQn.

CY_IRQ_PPCA_CPU0_CTI_1 

PPCA CPU0 Cross-Trigger Interface (CTI) channel 1.

Triggered by the CoreSight CTI output 1 of PPCA CPU0. Maps to host IRQn ppca_cpu0_cti_1_IRQn.

CY_IRQ_PPCA_CPU1_CTI_0 

PPCA CPU1 Cross-Trigger Interface (CTI) channel 0.

Triggered by the CoreSight CTI output 0 of PPCA CPU1. Maps to host IRQn ppca_cpu1_cti_0_IRQn.

CY_IRQ_PPCA_CPU1_CTI_1 

PPCA CPU1 Cross-Trigger Interface (CTI) channel 1.

Triggered by the CoreSight CTI output 1 of PPCA CPU1. Maps to host IRQn ppca_cpu1_cti_1_IRQn.

CY_IRQ_PPCA_CPU0_FP 

PPCA CPU0 Floating Point exception.

Triggered when a floating-point exception occurs on PPCA CPU0. Maps to host IRQn ppca_cpu0_fp_IRQn.

CY_IRQ_PPCA_CPU1_FP 

PPCA CPU1 Floating Point exception.

Triggered when a floating-point exception occurs on PPCA CPU1. Maps to host IRQn ppca_cpu1_fp_IRQn.
