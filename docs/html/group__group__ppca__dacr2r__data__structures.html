bool offset_correction_disable Offset Correction is added to DOUT value before sending to R2R_DAC Analog module.

false: correction enabled. true: correction disabled.

bool gain_correction_disable Gain Correction is added to DOUT value before sending to R2R_DAC Analog module.

false: correction enabled. true: correction disabled.

false: correction enabled. true: correction disabled.

bool vref_to_buf_enable Enable VREF as reference to Buffer.

false - VREF is not connected as reference true - VREF is connected as reference.

bool dac_out_to_buf_enable Enable DAC_Output as reference to Buffer.

false - DAC_Output is not connected as reference. true - DAC_Output is connected as reference.
